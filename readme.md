# 🛒 ShopSphere – JavaScript E-Commerce Store

ShopSphere is a fully responsive front-end e-commerce application built using HTML, CSS, Bootstrap, and Vanilla JavaScript. It simulates a real online shopping experience by allowing users to browse products, search, filter, manage a shopping cart, add items to a wishlist, and complete a checkout process with persistent data stored in Local Storage.

-----------------------

## 🚀 Features

### 🏠 Home Page
- Display all products
- Search products by title
- Filter products by category
- Filter products by price range
- Sort products by price (Low → High / High → Low)
- Filter products by ratings
- Reset all applied filters
- View product details
- Add products to Cart
- Add products to Wishlist

---

### 📦 Product Details
- View complete product information
- Add product to Cart
- Add product to Wishlist

------------------------------

### ❤️ Wishlist
- View saved wishlist items
- Remove products from wishlist
- Move products to cart

-------------------------------

### 🛍️ Shopping Cart
- View selected products
- Increase or decrease quantity
- Remove items from cart
- Automatic subtotal calculation
- GST calculation
- Discount calculation
- Shipping charges calculation
- Final bill calculation

-------------------------------

### 💳 Checkout
- Customer information form
- Form validation
- Payment method selection (just select method and show in user information)
- Order summary
- Order saved in Local Storage

-------------------------------

###  Success Page
- Display latest order information
- Display purchased products
- Show customer information
- Show payment method
- Show final bill

-------------------------
